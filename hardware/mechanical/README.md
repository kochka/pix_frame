# Mechanical parts

This directory is reserved for CAD sources and 3D-printable frame and PCB-support
parts. No printable model is supplied yet.

Keep editable CAD sources here, with intentionally published STL/3MF exports
alongside the corresponding design. Document dimensions, units, orientation and
any print settings needed for assembly when adding a part.

Electronic component models used only by KiCad's 3D viewer remain in
[`../pcb/pixframe.3dshapes/`](../pcb/pixframe.3dshapes/).
